# ITC-PRJCT

Landing page komunitas teknologi dan kreativitas yang menampilkan hero section, about, division spotlight, proyek, dan informasi lokasi dalam satu halaman statis.

## Tech Stack

- HTML
- CSS
- JavaScript

## Font

Website ini menggunakan Google Font **Pixelify Sans** untuk memberi nuansa pixel dan retro yang selaras dengan visual halaman.

## Palet Warna

Warna utama yang dipakai pada website ini:

- `#001F3F` - navy gelap untuk area utama dan blok latar
- `#0A1992` - biru kuat untuk aksen, panel, dan elemen penegas
- `#F5F5F5` - abu sangat muda untuk latar terang dan kontras teks

## Cara Menyalakan Website

1. Clone repository ini ke komputer lokal.

```bash
git clone <url-repository>
```

2. Masuk ke folder project hasil clone.

```bash
cd ITC-PRJCT
```

3. Buka folder project di Visual Studio Code.

4. Pastikan ekstensi **Live Server** sudah terpasang.

5. Klik kanan pada file `index.html`, lalu pilih **Open with Live Server**.

6. Browser akan terbuka otomatis dan website siap dijalankan.

## Catatan

- Jika ingin mengganti tampilan, ubah file CSS di `assets/css/style.css`.
- Karena proyek ini berbasis statis, tidak ada proses build tambahan sebelum dijalankan.
